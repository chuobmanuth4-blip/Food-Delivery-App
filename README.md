# Food-Delivery-App

## Overview

This project is a full-stack food delivery system that enables users to browse restaurants, view menus, place orders, and manage deliveries. The application is built with Java for backend logic and MySQL for relational data storage, focusing on reliability and clean system design.

## Project Goals

+ Provide a smooth food-ordering experience

+ Practice database design and SQL integration

+ Implement real-world CRUD operations

+ Strengthen Java backend development skills

## Technology Stack

+ Java

+ NetBean

+ MySQL

+ JDBC

+ Jaspersoft Studio
  
## Core Features

+ User registration and login

+ user, order and product management

+ Order processing

+ Admin dashboard

+ Print Receipt

## Setup and Run

+ Clone the repository

+ Open in IntelliJ IDEA or Eclipse or NetBean

+ Create the MySQL database and import schema

+ Update database credentials in the configuration file

+ Run the application
